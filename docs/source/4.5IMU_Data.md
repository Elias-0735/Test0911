4.5 IMU Data
===============

The system currently has three IMUs (2 LiDARs + 1 automotive‑grade). Data is published via ROS2 topics using the standard `sensor_msgs::msg::Imu` message type:<br>
Front LiDAR IMU: `/front_lidar/imu`<br>
Rear LiDAR IMU: `/rear_lidar/imu`<br>
Automotive-grade IMU: `/imu_driver/imu_central`<br>
**Note: The automotive‑grade IMU involves hardware modifications. If IMU data cannot be retrieved, please contact after‑sales support**
