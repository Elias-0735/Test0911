4.3 Ultrasonic Radar Data
======================

4.3.1 ROS2 Interface Definition
----------------------

| topic | msg | Field Type | Field | Field Description | Default | Range | Frequency |
|-------|-----|---------|-----|---------|-----|--------|---------|
| Left ultrasonic radar:/uss_driver/uss_left/range<br>Right ultrasonic radar:/uss_driver/uss_right/range | sensor_msgs::msg::Range | std_msgs/Header | header | ROS2 standard message header | | | 10hz |
| | | uint8_t | radiation_type | Sensor type. Enum values: 0 = ultrasonic, 1 = infrared | 0 | 0-1 | |
| | | float | field_of_view | Sensor field of view (radians); typically the angle of the conical ranging area | 0 | Currently fixed at 0 | |
| | | float | min_range | Sensor minimum measurable distance (meters) | 0 | Currently fixed at 0 | |
| | | float | max_range | Sensor maximum measurable distance (meters) | 0 | Currently fixed at 0 | |
| | | float | range | Current actual distance measured (meters) | 0 | 0-4m | |

4.3.2 Retrieving Ultrasonic Radar Data
----------------------

```
ros2 topic echo /uss_driver/uss_left/range --once
ros2 topic echo /uss_driver/uss_right/range --once
```
