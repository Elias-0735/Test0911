2.7 Demo Execution
========================

On the local PC, navigate into the SDK directory

```
# Enter the C++ demo directory
cd example

# Create a build directory
mkdir build && cd build

# Configure and build the project
cmake ..
make -j6

# Run the demo executable
./example_data 192.168.168.168 8081 #有线连接
./example_data 192.168.234.1 8081   #无线连接
```

**Before running the demo executable, ensure that the remote controller app has been closed in the background**
