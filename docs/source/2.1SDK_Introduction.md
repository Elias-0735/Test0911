2.1 SDK Introduction
==============

- This document describes the Software Development Kit (SDK) for the D1 Max, providing detailed information on its core service interfaces, including high‑level command set interfaces, Inertial Measurement Unit (IMU) inertial navigation data interfaces, and motor status data interfaces.
- Each chapter describes the invocation methods for different service interfaces, the standard format definitions for data input/output, and provides functional development examples.
- Interface definitions are subject to change based on production development status. Please refer to the latest version of the interface definition document.
- The SDK communicates with the quadruped robot body program via a specific protocol. Therefore, different SDK versions may have compatibility differences with the robot body software. Please select the SDK version that corresponds to the device version. If conditions permit, it is recommended to update the quadruped robot firmware to the latest version for better compatibility.
- When controlled via the SDK interfaces, all states are designed and specified by the secondary developer. The robot body motion controller does not perform additional intervention or state transitions.
- When running the SDK, please ensure that the system has sufficient resources; otherwise, the motion control module may fail.
