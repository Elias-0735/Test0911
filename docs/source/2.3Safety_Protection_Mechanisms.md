2.3 Safety Protection Mechanisms
==================

2.3.1 Hard Emergency Stop
--------------------------

- Trigger Method: Press the emergency stop button on the robot body
- Effect: The robot is slowly lowered to the ground, and the red indicator light illuminates
- Indicator Light Status
    * When pressed: Red light on
    * After release: Green light on
- Recovery: Once the system status is reset, the system automatically recovers (provided no other faults exist)

2.3.2 Soft Emergency Stop
--------------------------

- Trigger Method: Via the remote controller or via the SDK interface
- Effect: The robot stops immediately and no longer responds to any control commands
- Recovery: Normal operation can resume after releasing the soft emergency stop

**Starting from SDK version V0.0.6, the system allows users to switch between remote controller mode and SDK mode. Before triggering the soft emergency stop via the remote controller during SDK control, you must open the App and enable control authority. Once acquired, you can trigger a soft emergency stop at any time using the red emergency stop button at the upper right of the remote controller. After the soft emergency stop is triggered, the robot displays a red light, maintains its current posture, and does not respond to any control commands. Press the emergency stop button on the remote controller again to resume operation.**

2.3.3 Internal Exception Protection (Automatic Trigger)
---------------------------

The following conditions will trigger the internal protection mechanism, causing the robot to automatically stop and lower itself to the ground slowly:
- Remote control signal disconnection (including network congestion); reconnection via the APP will restore operation
- Battery present but charge level < 10%
- Joint fault
- IMU communication interruption
