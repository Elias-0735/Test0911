2.2 SDK Software Service Interface List
========================

| No. | Interface Name | Function | SDK Version |
|-----|---------|------|--------|
| 1 | High‑Level Command Set Interface | Implements high‑level command set of the robot, including forward/backward and turning motion, prone posture, rotation, and standing on all fours | V0.0.2 |
| 2 | Video Stream Push Data Interface | Streams the robot body camera's video feed to the client | V0.0.2 |
| 3 | Device Status Service Interface | Queries and retrieves current device status and system resource usage information | V0.0.3 |
| 4 | Inertial Navigation Status Data Interface | Retrieves raw IMU data | V0.0.4 |
| 5 | Ultrasonic Radar Interface | Implements autonomous obstacle-avoidance functionality | v0.0.5 |
| 6 | Remote Controller & SDK Control Authority Switching Function and SDK Interface | Implements control authority switching functionality | v0.0.6 |
| 7 | RTK Module Interface | Implements autonomous positioning functionality | v0.0.6 |
| 8 | Autonomous Docking & Recharging Function and API Interface(Optional) | Implements autonomous charging functionality | v0.0.9 |
| 9 | SLAM Mapping & Navigation Function and API Interface(Optional) | Implements autonomous navigation functionality | v0.1.0 |
