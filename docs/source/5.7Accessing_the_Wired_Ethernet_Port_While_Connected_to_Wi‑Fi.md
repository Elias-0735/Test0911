5.7 Accessing the Wired Ethernet Port While Connected to Wi‑Fi
==============================

When connected to the device's AP hotspot (XG2WIFI_xxxxx), add the following route to enable access to the device's wired Ethernet port while connected to Wi‑Fi:

Windows System:

```
route -p ADD 192.168.168.0 MASK 255.255.255.0 192.168.234.1
ping 192.168.168.168
ping 192.168.168.100
```

Linux System:

```
sudo ip route add 192.168.168.0/24 via 192.168.234.1
ping 192.168.168.168
ping 192.168.168.100
```
