2.6 Obtaining the SDK
===================

way1：
-------------------

SSH into the robot body, query the current firmware version information, and send a screenshot of the quadruped robot's firmware version number to the after‑sales technical support team to obtain the corresponding SDK package and example code. The query method is as follows:

```
ssh robot@192.168.234.1        #password: bot
cat /opt/release/version.yaml  #View RK-corresponding firmware version

ssh robot@192.168.168.100        #password: 1
cat /opt/release/version.yaml    #View NX-corresponding firmware version
```

-------------------

git clone https://github.com/AgibotTech/Agibot_D1_Max.git
