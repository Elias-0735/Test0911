4.2 LiDAR Data
====================

4.2.1 ROS2 Interface Definition
--------------------

| topic | msg | Field Type | Field | Field Description | Default | Range | Frequency |
|-------|-----|---------|-----|---------|-----|--------|---------|
| Front LiDAR point cloud: /front_lidar<br>Rear LiDAR point cloud: /rear_lidar | sensor_msgs::msg::PointCloud2<br>（Qos::best_effort） | std_msgs/Header | header | ROS2 standard message header | | | 10hz |
| | | uint32 | height | Vertical height of the point cloud (rows) | | | |
| | | uint32 | width | Horizontal width of the point cloud (columns) | | | |
| | | PointField[] | fields | Field descriptors for each channel in the point cloud | | | |
| | | bool | is_bigendian | Whether the data is in big‑endian byte order | | | |
| | | uint32 | point_step | Number of bytes per point | | | |
| | | uint32 | row_step | Number of bytes per row of point data | | | |
| | | uint8[] | data | Raw binary point cloud data as a 1D array | | | |
| | | bool | is_dense | Whether the point cloud is dense (i.e., contains no invalid points) | | | |

**Front LiDAR IP: 192.168.1.102**<br>
**Rear LiDAR IP: 192.168.2.102**

4.2.2 Retrieving LiDAR Data
--------------------

```
ssh robot@192.168.168.100   
ros2 topic echo /front_lidar --once
ros2 topic echo /rear_lidar --once
```
